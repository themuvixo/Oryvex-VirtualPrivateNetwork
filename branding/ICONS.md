# OryvexVPN icons

The app icon is the **open orbit**: a ring with its gap at the upper right (-45 deg) and the core
parked just outside it, on its way out. It is the same geometry as the Connect orb in the app,
so the icon, the hero control and the installer art now tell one story (the old shield did not).

| File | Use |
| --- | --- |
| `oryvexcore-logo.svg` / `-mark.svg` | Full tile, 40 px and up |
| `oryvexcore-small.svg` | Tile tuned for 16-32 px: heavier ring, wider gap, bigger core |
| `oryvexcore-adaptive-foreground.svg` | Android adaptive foreground (on `#0A6CFF`), inside the 66dp safe zone |
| `oryvexcore-glyph-white.svg` / `-glyph-blue.svg` | Bare mark for dark / light surfaces |
| `oryvexcore-1024.png` / `-256.png` | Store and README rasters |

Colours: tile gradient `#2B83FF` to `#0656E6`, adaptive background `#0A6CFF`, mark `#FFFFFF`.
ICO files carry 16, 20, 24, 32 (small tile) and 40, 48, 64, 128, 256 (full tile).
