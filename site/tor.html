Tor

Tor, built in.

Arti, the Rust implementation of Tor, runs inside OryvexCore. Use it on its own, inside the tunnel, or carry the tunnel through it.

Three modes

Pick how Tor fits in.

Tor alone

No tunnel, no WARP identity. The proxy is plain Tor. In the apps this is the Tor route.

YouTorInternet
oryvexcore --tor-only

Tor through the tunnel

Tor rides inside WARP, so a network that blocks Tor never sees it. Tor proxy on 127.0.0.1:1820.

YouWARPTorInternet
oryvexcore --masque --tor

The tunnel through Tor

Tor first, then WARP is dialled through it. You leave from a WARP exit. MASQUE over HTTP/2 only, Tor carries TCP.

YouTorWARPInternet
oryvexcore --masque --tor-reverse

Check you're on Tor

Ask the Tor Project which address it sees.

curl -x socks5h://127.0.0.1:1820 https://check.torproject.org/api/ip
Exit choice

Leave from where you want.

ValueWhat happens
--tor-exit autoDefault. Tor picks an exit itself, weighted by bandwidth.
--tor-exit fastestOn every connect, tests exits in the 6 best-served countries and keeps the quickest.
--tor-exit de,nl,seLeave from that country, first that answers.
--tor-exit-strictFail instead of falling back to another country.

The exit list is only ever fetched through Tor itself, then cached in <tor-dir>/exits.json. Until then a bundled list of 32 exit countries is used, resolved locally by Arti's GeoIP table.

Bridges

When Tor itself is blocked.

OryvexCore tries Tor plainly for a moment, then fetches bridges and pluggable transports on its own. You can bring your own too.

oryvexcore --tor-only \
  --tor-bridge "obfs4 192.0.2.55:38114 FINGERPRINT cert=... iat-mode=0" \
  --tor-pt /usr/bin/lyrebird
FlagDefaultWhat it does
--tor-bind127.0.0.1:1820The Tor proxy address
--tor-dir<config>-torDirectory cache and state
--tor-bridgefetched as neededBridge lines; repeat for more
--tor-bridge-fileYour own bridge lines from a file
--tor-bridgesGo to bridges at once
--no-tor-bridgesNever use bridges
--tor-ptfound on its ownPluggable transport binaries
--tor-pt-dirpt/ beside the binaryAnother folder to search
Under the hood

Where Tor lives in the code.

Tor is a cargo feature, off by default. Plain cargo build gives a core with no Tor. Build with scripts/build-core.sh (what CI and Docker use) or --features tor,tor-exit-country.

cd oryvexcore
bash scripts/build-core.sh cargo build --release   # tor + exit country, falls back on tor
cargo build --release --features tor,tor-exit-country
FileWhat's in it
oryvexcore/src/tor.rsThe Arti client: modes (alone, through, reverse), bootstrap, the 1820 proxy
oryvexcore/src/tor_exits.rsExit-country choice: auto, fastest, country list, cache
oryvexcore/src/bridges.rsBridge fetching and pluggable transports
oryvexcore/src/cli.rsThe --tor* flags
oryvexcore/Cargo.tomlThe tor and tor-exit-country features (arti-client 0.46)
oryvexcore/scripts/pt-build.shBuilds the pluggable transports shipped in pt/
apps/shared/.../tor_exit_picker.dartThe exit picker in the Windows and Android apps
oryvexcore/tor/exit-nodes.txtLatest Tor exit IPs from the Tor Project, refresh with tools/update-tor-exits.sh
docs/TOR.mdTor route and exit selection notes
